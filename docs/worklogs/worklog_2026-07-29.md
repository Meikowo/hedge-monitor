  保证金、衍生金融资产/负债/净额、三类损益、套期会计、匹配/证据状态及 PDF。

  分项可由品种或列示科目明确区分时才在主表求和，并标注“合计 · N 项”；原始分项仍
  留在右侧证据详情。
- 修复 `null` 被 JavaScript 转换成数值 0 的风险；缺失或歧义事实在 CSV 中保持空值，
  不参与合计。每类数值同时导出币种、单位和事实数。

  不会被映射为衍生品综合损益。
