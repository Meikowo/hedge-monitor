## 定位器升级

- `periodic_pdf.py` 升级至 `v2.2`。
- 分别为业务、套期会计、投资收益、公允价值变动损益、OCI、衍生金融资产、负债、
  保证金和公司专属品种保留候选页。

- 五份新样本均确认 15/15 个候选页实际进入模型正文；晶科保留旧结果作为人工对照。

## LLM 调用问题与修复

- 单次输出全部字段会生成未闭合 JSON；根因是年报事实过多，输出超过兼容接口完成长度。
- 抽取改为四段短输出：报告/套期会计、业务规模、损益、期末头寸与保证金。
- 新增 `--pass`，可只重跑某一个短批次，不重复调用其他部分。
- 修复 `LLM_THINKING=off` 只省略参数、未明确发送 `disabled` 的问题。
- 空正文和截断 JSON 不再自动重复同一请求，避免无效消耗。
- Windows 本地增加 `socksio` 依赖，并移除探活日志中的 GBK 不兼容符号。
- 数值回验新增“损失”文字和会计括号负数；报表横线不得解释成 0。
