# 定期报告导出与同类别多品种聚合设计

## 目标

在不改变“公司 × 报告期 × 类别”主表粒度的前提下：

1. 为“计划与实际”增加“导出当前结果”按钮；
2. 对同一类别内可安全相加的多品种事实显示合计；
3. 继续在证据详情中保留每一个原始分项，不损失页码和引文。

## 聚合规则

- 只聚合同一 `metric_type`、`fact_level`、`scope`、`currency`、`unit` 和
  `time_basis` 的双回验事实。
- 每个分项必须有非空有限数值，并能由 `underlying` 或 `account_name` 明确区别；只靠
  原文措辞不同不足以证明是两个经济事实。
- 报告级多事实可能同时包含合计与分项，不自动相加；本轮只聚合明确归属于当前类别的
  非报告级事实。
- 满足条件时主表显示数值合计，并标注“合计 · N 项”；详情抽屉仍逐项显示。
- 任一口径不一致或无法区分分项时不求和，主表显示“N 项事实”，引导查看详情。
- 不跨指标推断：公允价值变动损益不填入“综合损益”，OCI 也不替代综合损益。

锐新科技 2025FY 因此显示：

- 报告期购入：`3,505.10 万元`；
- 报告期售出：`3,558.64 万元`；
- 公允价值变动损益：`53.54 万元`；
- 详情保留铝期货 `18.55 万元`、铜期货 `34.99 万元`。

## CSV 导出

- 按当前搜索和全部筛选条件导出完整结果，不受屏幕可见行或分页影响。
- 一行仍表示“公司 × 报告期 × 类别”。
- 字段包括报告、公司、地区/行业/性质、类别、品种、工具、公告候选、交易流量、
  保证金、衍生金融资产/负债/净额、三类损益、套期会计、匹配状态、证据状态和 PDF。
- 数值、币种与单位分列；安全聚合值导出为合计，同时增加分项数量。
- 使用 UTF-8 BOM，确保 Excel 直接打开中文不乱码。
- 无结果时不下载空文件，显示提示。

## 组件边界

- `periodic.js` 提供纯函数完成兼容聚合、筛选结果序列化和 CSV 生成。
- DOM 层只负责按钮事件、下载和提示，不复制指标计算规则。
- 不修改 Supabase 表结构、数据内容、RLS 或年报提取脚本。
